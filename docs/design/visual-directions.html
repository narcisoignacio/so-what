So What? · Visual directions

M3a, board 1. Three visual worlds, each drawn on the same place panel and the same map crop over the real Stadia tiles (Alidade Smooth and Smooth Dark). Judge them the way the product will be judged: can someone who has never been to LA read one place's risks in 30 seconds, and is the So What? sentence the thing the eye lands on?

Illustrative content. The sentences come word for word from the voice doc's templates. The place, the numbers, the pins and the nearby list are invented for this board. They are not M1 data. Tiles load only when this page is served from localhost (python3 -m http.server from the repo root), because Stadia authorizes by domain.

Pictogram plates

The risk glyph and its name always appear together as one unit, at set sizes: card headings, chips, legend. No component shows a glyph alone.

The hatch means "Projected"

One fine diagonal hatch marks every projection (the trend-line label, the sea-level card, the dashed pin, the legend entry) and nothing that isn't one.

Region labels

Map, legend and place panel each carry a small label that matches the landmark name a screen reader announces.

A · Field brochure

From the National Park Service's Unigrid brochures: black title bands, a strict grid, and a map beside the one line you must read.

Each place is a brochure panel. A black band names it, and the So What? sentence is the largest type on the page, the way a park brochure prints "Heat can kill. Carry water." above everything else. It works in black and white first. Colour is kept for one thing: the place you've selected.

Palette
Ink and paper; pins in three greys; one ultramarine for the selected place and focus.
Type
Archivo only. Condensed for bands and place names, regular width for reading.
Borrowed discipline
Black and white first (HyperCard) · poster-scale So What? (Metro tiles) · one accent, only for selection (origami crane) · one family (phosphor terminal).
Honest risk
It can read as a government publication, so "not an official hazard assessment" has to stay visible. The black bands are heavy at 320px. Grey pins on grey tiles depend entirely on the halo.

B · Street atlas

From LA's spiral-bound street atlas: the yellow cover, index tabs on the page edge, grid letters around every map, dotted leaders in the index.

The site is an atlas of everyday places. The map sits in a lettered grid frame. "Nearby places" reads as an atlas index, with dotted leaders out to the distance. Section names sit on black thumb tabs. Levels print in overprint violet, as if a second colour ran through the press.

Palette
Cover yellow as a field; ink; overprint violet for levels (pale to deep); an off-grey for index strips.
Type
Barlow Condensed for tabs, place names and distances; Barlow for reading. One superfamily, with California road-sign ancestry.
Why it's here
My own top-ranked candidate, shown next to the one the roll assigned.
Honest risk
It's familiar ground: this is where a run like this usually lands. It carries strong nostalgia for Angelenos and means little to a grader outside LA. It must never borrow Rand McNally's branding. The grid letters are framing, not coordinates anyone uses.

C · The standard map app

The category standard, played straight: the look of the mainstream map and air-quality apps.

White rounded cards on a light grey panel, a system font, coloured pill badges for levels, teardrop pins. It's familiar, so nobody has to learn it. It's on the board as the reference point for A and B, not as a recommendation.

Palette
White and grey surfaces, link blue, a yellow-orange-red level ramp.
Type
The platform system font.
Honest risk
The So What? sentence ends up the same size as everything else, and the coloured badge becomes what the eye lands on, which works against principle 1. It looks like every other map, so it's easy to forget. The red end of the ramp reads as alarm.

Choosing

  1. Squint at each desktop frame. What does your eye land on first? It should be the So What? sentence, not a badge, a band or a pin.
  2. Read the 320px frames as a stranger would. Imagine you've never been to Wilmington. Which one tells you what's wrong at this stop, and what to do, fastest?
  3. Switch each map to dark tiles. Pin colours aren't final (that's board 2), but the world has to survive both backgrounds.
  4. Picture it one level down: the About page, a "not found" page, the loading state. Which world still has something to say there?

Pick one, or name what to carry from one into another. The chosen world goes on to board 2 (pin palette and legend, measured on these tiles), then the glyph pass, then DESIGN.md.
